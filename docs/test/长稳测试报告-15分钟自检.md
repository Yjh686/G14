## 5. 复查清单

长稳测试期间除了故障率，还要确认这些「慢性病」没有发生：

- [ ] 服务未重启（`Backend1Application` 的启动日志只有一条）
- [ ] 无 OOM（日志中无 `OutOfMemoryError`）
- [ ] 无连接池耗尽（日志中无 `Connection is not available`）
- [ ] 数据库连接数没有单调增长（`SHOW STATUS LIKE 'Threads_connected'`）
- [ ] 日志文件没有撑爆磁盘（`logging.logback.rollingpolicy.max-total-size`）
