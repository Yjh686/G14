# 权限矩阵（Role / Permission Matrix）

> 依据 `AGENTS.md`：三角色（ADMIN / TEACHER / STUDENT），"问卷发布者"是权限而非角色。
> 本文档是**后端接口鉴权**的唯一依据，前端菜单/按钮显隐也按此表实现（但前端不作为安全边界）。

## 1. 角色定义

| 角色码 | 名称 | 说明 |
|---|---|---|
| `ROLE_ADMIN` | 系统管理员 | 全量权限，负责账号、权限、模板审核、日志、配置 |
| `ROLE_TEACHER` | 教师 | 创建并管理**自己的**问卷，查看自己问卷的答卷/统计/导出，共享模板 |
| `ROLE_STUDENT` | 学生 | 填写问卷、保存草稿、查看自己的记录、浏览与评分模板 |

**硬规则**
1. 不新增第四个角色。学生干部需要发卷 → 给该用户单独授予 `survey:create` + `survey:publish:self`。
2. 一个用户只有一个主角色（`sys_user_role` 本期按一用户一角色实现，表结构预留多角色）。
3. 用户级追加权限（`sys_user_permission`）只做**加权限**，不做"减权限"（避免出现教师被削弱到无法工作的状态）。

## 2. 权限码清单

命名规则：`模块:动作[:范围]`，范围 `self` = 仅自己的资源，`all` = 全量。

### 2.1 认证与账号

| 权限码 | 说明 |
|---|---|
| `auth:login` | 登录（所有启用账号隐含具备） |
| `auth:logout` | 登出 |
| `auth:password:self` | 修改自己的密码 |
| `auth:profile:self` | 查看/编辑自己的资料 |

### 2.2 用户与权限管理

| 权限码 | 说明 |
|---|---|
| `user:list` | 用户列表查询 |
| `user:create` | 新增用户 |
| `user:update` | 编辑用户信息 |
| `user:delete` | 删除用户（软删） |
| `user:status` | 启用/禁用 |
| `user:reset-password` | 重置他人密码 |
| `user:import` | 批量导入 |
| `user:audit` | 审核自助注册 |
| `user:grant` | 分配角色 / 追加用户权限 |
| `role:list` | 角色列表 |
| `role:manage` | 角色与角色权限维护 |

### 2.3 问卷

| 权限码 | 说明 |
|---|---|
| `survey:create` | 创建问卷（**决定是否为"问卷发布者"**） |
| `survey:update:self` | 编辑自己创建的问卷 |
| `survey:update:all` | 编辑任意问卷（ADMIN） |
| `survey:delete:self` | 删除自己的问卷 |
| `survey:delete:all` | 删除任意问卷 |
| `survey:publish:self` | 发布/暂停/结束自己的问卷 |
| `survey:publish:all` | 对任意问卷强制下架/结束 |
| `survey:list:self` | 我的问卷列表 |
| `survey:list:all` | 全量问卷列表 |
| `survey:preview` | 预览问卷 |
| `survey:copy` | 复制问卷 |

### 2.4 填写与答卷

| 权限码 | 说明 |
|---|---|
| `survey:fill` | 填写问卷（学生默认具备） |
| `draft:save:self` | 保存/读取自己的草稿 |
| `answer:read:self` | 查看自己的填写记录 |
| `answer:read:survey:self` | 查看**自己问卷**的答卷列表与详情 |
| `answer:read:survey:all` | 查看任意问卷的答卷 |
| `answer:invalidate` | 标记答卷无效/恢复 |
| `answer:delete` | 删除答卷 |

### 2.5 统计与导出

| 权限码 | 说明 |
|---|---|
| `stat:read:self` | 查看自己问卷的统计 |
| `stat:read:all` | 查看任意问卷统计 |
| `export:self` | 导出自己问卷数据 |
| `export:all` | 导出任意问卷数据 |

### 2.6 模板

| 权限码 | 说明 |
|---|---|
| `template:browse` | 浏览已通过模板 |
| `template:share` | 将自己的问卷共享为模板 |
| `template:offline` | 下架自己的模板 |
| `template:audit` | 审核模板（通过/驳回） |
| `template:use` | 使用模板创建问卷 |
| `template:rate` | 评分（学生） |

### 2.7 系统

| 权限码 | 说明 |
|---|---|
| `log:login:read` | 登录日志 |
| `log:operation:read` | 操作日志 |
| `log:export` | 导出日志 |
| `config:read` | 读取系统配置（公开配置无需登录） |
| `config:manage` | 修改系统配置 |
| `dashboard:read` | 管理端数据看板 |
| `survey:manage:all` | 全量数据管理（聚合权限，ADMIN 专用） |

## 4. 数据范围规则（比权限更细的一层）

权限码决定"能不能做这个动作"，**数据范围**决定"对哪些数据能做"。

| 资源 | ADMIN | TEACHER | STUDENT |
|---|---|---|---|
| 问卷 | 全量 | `survey.create_by = 当前用户` | 仅可填、不可管 |
| 题目 / 选项 | 全量 | 所属问卷属于自己 | — |
| 答卷 | 全量 | 所属问卷属于自己 | 仅自己的提交（`answer:read:self`） |
| 统计 / 导出 | 全量 | 所属问卷属于自己 | — |
| 模板 | 全量（含待审） | 自己共享的可下架；已通过的可见 | 仅已通过可见 |
| 日志 | 全量 | 无 | 无 |

**实现要求（必须遵守）**
- 所有列表查询在 Mapper 层拼接 `create_by = #{currentUserId}` 条件，**不允许**在内存里过滤。
- 所有按 id 操作的接口（详情、编辑、删除、统计、导出）必须先查资源并校验归属，归属不符返回 **403**，资源不存在返回 **404**。
- ADMIN 通过 `*:all` 权限绕过归属校验，但**仍需写操作日志**。

## 5. 匿名问卷的特殊约束

匿名开关打开时（`survey.is_anonymous = 1`）：

| 场景 | 行为 |
|---|---|
| 提交答卷 | 后端仍写入 `answer_sheet.user_id`（保证限填一次与"我的记录"） |
| 答卷列表接口 | **响应中不得包含** `user_id`、姓名、学工号字段（用 DTO 裁剪，不是前端隐藏） |
| 答卷详情接口 | 同上，不返回身份信息 |
| Excel 明细导出 | 不含填写人与学工号列 |
| 登录用户查看自己的记录 | 仅显示"已提交 + 时间"，不回显作答内容 |
| 日志 | 不记录"某用户提交了某匿名问卷"这类可反推身份的信息，仅记录提交计数 |

## 6. 接口级鉴权约定

| 项 | 约定 |
|---|---|
| 鉴权方式 | 请求头 `Authorization: Bearer <JWT>` |
| 后端实现 | 拦截器/过滤器解析 JWT → 加载用户权限集合 → 注解 `@RequirePerm("survey:publish:self")` 校验 |
| 未登录 | `401`，响应体 `{code:401, msg:"未登录或登录已过期"}` |
| 无权限 | `403`，响应体 `{code:403, msg:"无权限执行该操作"}` |
| 资源不属于自己 | `403`，msg 统一为"无权访问该资源"（不暴露资源是否存在细节） |
| 参数错误 | `400` |
| 业务规则不满足（如问卷已结束） | `200` + 业务码（如 `40901`），或 `409`，**全项目统一一种** |

| 用例 | 期望 |

| 未登录请求任意受保护接口 | 401 |
