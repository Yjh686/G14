## P2 明确不做（写进文档备查）

| 功能 | 不做原因 |
|---|---|
| 条件逻辑跳转 | 编辑器复杂度翻倍，课程周期内风险高 |
| 矩阵题 / 排序题 / 文件上传 | 无对应统计方案，收益低 |
| 题目 × 题目交叉分析 | 需要自定义报表引擎 |
| 微信 / 统一身份认证登录 | 依赖外部系统接入 |
| 短信 / 邮件通知 | 需要第三方服务与费用 |
| 多院系数据隔离 | 课程级规模无必要 |
| 答卷实时推送大屏 | 演示可用现成图表替代 |
