# 验收标准（Acceptance Criteria）

> 定义"做到什么程度算完成"。分三类：**功能验收**（逐用例）、**非功能验收**（两条硬指标）、**交付物验收**。
> 所有条目必须可执行、可复现、有明确判定标准。

## 1. 角色主流程验收（端到端，答辩演示脚本）

### AC-01 教师主流程（约 8 分钟）
| 步骤 | 操作 | 期望结果 |
|---|---|---|
| 1 | 教师用学工号+密码登录 | 进入教师工作台，菜单含"我的问卷/模板共享/个人中心"，无"用户管理" |
| 2 | 新建问卷，填标题/简介，设为匿名，设截止时间 | 进入编辑器，草稿自动保存 |
| 3 | 添加单选、多选、文本、评分各 1 题，设置选项与必答 | 拖拽调整顺序后刷新页面顺序不变 |
| 4 | 预览问卷 | 学生视角渲染，无提交按钮或提交不产生数据 |
| 5 | 发布问卷 | 状态变为已发布，题目不可再编辑，生成分享链接+二维码 |
| 6 | 用另一浏览器以学生身份通过分享链接登录并填写提交 | 提交成功，显示回执 |
| 7 | 教师查看答卷列表与单题统计 | 回收数=1，各图表数值正确，匿名卷不显示填写人 |
| 8 | 导出 Excel | 下载成功，两个 Sheet，中文不乱码，无填写人列 |
| 9 | 暂停问卷，学生再提交 | 被拒绝并提示"问卷已暂停" |

### AC-02 学生主流程（约 4 分钟）
| 步骤 | 操作 | 期望结果 |
|---|---|---|
| 1 | 学生登录 | 进入问卷大厅，看到可填问卷 |
| 2 | 打开问卷，答 2 题后关闭浏览器 | 草稿已保存 |
| 3 | 重新登录进入同一问卷 | 已答内容恢复，可继续作答 |
| 4 | 不答必答题直接提交 | 定位到该题并高亮提示 |
| 5 | 补全后提交 | 提交成功，记录出现在"我的记录" |
| 6 | 再次进入该问卷 | 显示"已提交"，不可重复作答 |
| 7 | 进入模板中心，浏览已通过模板并评分 | 评分生效，均值更新，一人只能一票 |

### AC-03 管理员主流程（约 5 分钟）
| 步骤 | 操作 | 期望结果 |
|---|---|---|
| 1 | ADMIN 登录 | 看到全部管理菜单 |
| 2 | 新增一个教师账号 | 该账号可登录并具备教师权限 |
| 3 | 给某学生追加 `survey:create` 权限 | 该学生可创建问卷，但看不到他人问卷 |
| 4 | 禁用该学生账号，学生已登录页面再操作 | 请求被拒，前端跳登录 |
| 5 | 审核一条模板：驳回并填原因；再通过另一条 | 驳回的模板作者可见原因；通过的出现在模板中心 |
| 6 | 查看登录日志与操作日志 | 含上述登录、禁用、审核记录 |
| 7 | 尝试禁用自己 | 被拒绝并提示 |

## 2. 功能验收清单（逐条）

### 2.1 问卷编辑器
- [ ] 五种题型均可正常创建、编辑、渲染
- [ ] 单选题必须且只能选一个；多选题至少一个；评分题取值 1–5
- [ ] 选项少于 2 个时保存被拒并提示
- [ ] 删除题目后其余题目序号连续
- [ ] 未保存离开页面有提示（或自动保存后无数据丢失）
- [ ] 发布后再进入编辑器，题目控件为只读，仅标题/简介/截止时间可改

### 2.2 填写与提交
- [ ] 必答题全空提交被拦截，并滚动定位到第一个错误题
- [ ] 文本题超过字数上限被拦截
- [ ] 网络中断后重试提交，不产生两份答卷（幂等）
- [ ] 两个浏览器窗口同时提交同一问卷，仅一份入库，另一份提示"已提交"
- [ ] 已结束/已暂停/已过期问卷无法进入填写页
- [ ] 匿名问卷提交后个人中心不回显答案内容

### 2.3 统计准确性（用构造数据核对）
- [ ] 单选：各选项人数之和 = 有效答卷数
- [ ] 多选：任一选项占比 ≤ 100%，各选项占比之和可 > 100%（分母为答题人数）
- [ ] 评分：平均分与手工计算一致（保留 1 位小数）
- [ ] 标记某答卷无效后，所有统计数值同步减少
- [ ] 无答卷时统计页显示"暂无数据"，无 NaN/报错

### 2.4 导出准确性
- [ ] 明细 Sheet 行数 = 有效答卷数
- [ ] 明细列数 = 1（提交时间）+ 题目数（非匿名时多 1 列填写人）
- [ ] 多选题在单元格内以分隔符（如 `;`）展示全部所选
- [ ] 汇总 Sheet 数值与页面统计一致
- [ ] 中文标题、题目、选项在 Excel 中不乱码
- [ ] 5000 行数据导出过程服务不崩溃、内存不持续增长

### 2.5 权限与数据范围
- [ ] 见《权限矩阵》第 7 节全部用例通过
- [ ] 前端通过直接调用接口（Postman）无法越权，返回 403
- [ ] 教师 A 无法通过修改 URL 中的 id 访问教师 B 的问卷/答卷/统计/导出

### 2.6 模板中心
- [ ] 未审核模板不出现在模板中心
- [ ] 驳回必须填原因，作者能看到原因
- [ ] 使用模板生成的问卷为独立草稿，修改不影响模板
- [ ] 同一学生重复评分不产生多条记录，修改后均值随之变化

## 3. 非功能验收（硬性指标）

### 3.1 指标一：并发答卷响应时间 < 3 秒

| 项 | 内容 |
|---|---|
| **判定标准** | 100 并发下，答卷**提交接口** P95 < 3000ms，且平均 < 1500ms |
| 测试环境 | 单机部署（后端 1 实例 + MySQL 同机或同网段），需在报告中注明 CPU/内存配置 |
| 数据准备 | 1 份已发布问卷（10 题，含各题型），预置 500 份历史答卷 |
| 压测脚本 | JMeter：100 线程，ramp-up 10s，循环 5 分钟；混合比例 查询问卷 20% / 保存草稿 10% / 提交答卷 70% |
| **通过条件** | ① P95 < 3s；② 平均 < 1.5s；③ 错误率 < 0.1%；④ 答卷表记录数 = 成功提交数（无重复、无丢失）；⑤ 无 5xx；⑥ MySQL 无死锁日志 |
| 证据 | JMeter 聚合报告截图 + 结果 `.jtl` + 数据库计数 SQL 结果截图 |
| 不通过时的排查方向 | 慢 SQL（开启慢查询日志）、连接池大小、索引缺失、统计接口未分页 |

### 3.2 指标二：长期运行故障率 < 0.1%

| 项 | 内容 |
|---|---|
| **故障定义（口径）** | 故障请求 = HTTP 5xx 响应 + 请求超时 + 连接被拒。**4xx（未登录/无权限/参数错误/业务拒绝）不计入故障**，单独统计为"业务拒绝率" |
| **计算公式** | 故障率 = 故障请求数 ÷ 总请求数 × 100% |
| 测量方式 1 | 24 小时持续压测（可用较低并发如 20 线程循环），统计 JMeter 报告中 error% 中属于 5xx/超时的比例 |
| 测量方式 2 | 答辩前实际使用期（≥ 3 天）的 Nginx access log 统计：`grep ' 5[0-9][0-9] ' access.log | wc -l` ÷ 总行数 |
| **通过条件** | 两种方式计算结果均 < 0.1%；且期间无服务重启、无 OOM、无连接池耗尽告警 |
| 附加要求 | 提供内存占用随时间曲线（如 `jstat`/Actuator 采样），证明无内存泄漏 |
| 证据 | 24h 压测报告、日志统计脚本与输出、监控截图 |

> ⚠️ 两条指标的口径必须在答辩 PPT 中明确写出，否则评委会质疑"3 秒"和"0.1%"的测量方式。

## 4. 安全验收
- [ ] 数据库中密码字段为 BCrypt 哈希（形如 `$2a$...`），无明文
- [ ] 任意接口响应中不出现 `password` 字段
- [ ] 使用 SQL 注入 payload（`' OR 1=1 --`）测试搜索接口，无异常行为
- [ ] 文本答案中包含 `<script>alert(1)</script>`，在统计页与导出中不被执行
- [ ] JWT 篡改（改 payload 不改签名）后被拒
- [ ] 过期 token 请求返回 401
- [ ] 连续 5 次密码错误后账号锁定，提示锁定剩余时间

## 5. 可用性验收
- [ ] 所有列表有分页，每页默认 10–20 条
- [ ] 所有列表有空状态文案（如"暂无问卷，去创建"）
- [ ] 所有提交类操作有成功/失败提示
- [ ] 表单校验错误定位到字段
- [ ] 填写页显示进度（当前题号/总题数）
- [ ] 1280×720 分辨率下无横向滚动条、无元素重叠

## 7. 缺陷分级与放行标准

| 级别 | 定义 | 示例 |
|---|---|---|
| S1 致命 | 主流程阻断、数据丢失、安全漏洞 | 无法登录、提交报错、越权可读他人数据 |
| S2 严重 | 功能不可用但有替代路径 | 导出失败、统计数值错误 |
| S3 一般 | 体验问题 | 提示文案错误、排序不稳定 |
| S4 轻微 | 样式问题 | 间距、对齐 |

**放行标准（答辩前）**：S1 = 0，S2 = 0，S3 ≤ 5 且不影响演示路径。
