# 问卷管理 接口文档

> 模块：问卷创建编辑（SUR） + 发布分发（PUB）
> 版本：v1.0
> 服务地址：`http://localhost:8080`，统一前缀 `/api`
> 通用约定（响应体、鉴权、状态码、时间格式）见 `docs/api/认证与用户管理接口.md` 第 0 章，本文不再重复。

## 1. 设计要点（读接口前先看这段）

### 1.1 两层权限校验

| 层 | 在哪做 | 决定什么 |
| --- | --- | --- |
| 方法级 | `@RequirePerm` 注解 + `AuthInterceptor` | 「这个人能不能执行这个动作」，如学生不能建卷 |
| 数据级 | `SurveyService.requireOwned()` | 「这个人能不能动这条数据」，如教师 A 不能改教师 B 的问卷 |

两层缺一不可。只做方法级 → 教师 A 能编辑教师 B 的问卷；只做数据级 → 学生能建自己的问卷。

数据级判定顺序：

1. 具备 `allPerm`（如 `survey:update:all`）→ 放行，跳过归属判断；
2. 具备 `selfPerm` 且 `createBy == 当前用户` → 放行；
3. `createBy != 当前用户` → **403 无权操作他人的问卷**；
4. 其余 → **403 您没有执行该操作的权限**。

问卷不存在（含已逻辑删除）统一 **404 问卷不存在或已被删除**，不区分「不存在」与「无权限」，避免通过状态码枚举他人问卷 ID。

### 1.2 状态机

```text
        ┌──────── publish ────────► PUBLISHED ◄──┐
        │  (需 ≥1 题，生成分享码)      │          │ resume
     DRAFT                           pause      │
        │                              ▼          │
        │                           PAUSED ───────┘
        │                              │
        └── close ─────────────► CLOSED ◄┘  (不可逆)
```

| 状态 | 可改题目 | 可改元信息 | 可填写 |
| --- | --- | --- | --- |
| `DRAFT` | ✅ | 全部字段 | ❌ |
| `PUBLISHED` | ❌ | 仅标题 / 简介 / 截止时间 | ✅（且需在时间窗内） |
| `PAUSED` | ❌ | 仅标题 / 简介 / 截止时间 | ❌ |
| `CLOSED` | ❌ | 仅标题 / 简介 | ❌ |

**为什么发布后锁题**：已回收的答卷按题目 ID 存储，改了题型或删了题目，答卷与题目就对不上，统计直接失真。要改结构就 `POST /api/surveys/{id}/copy` 复制成新草稿。

**为什么没有 DELETED 状态**：删除由 `deleted=1` 表达。同一个概念不设两处开关，否则必然出现「status=DELETED 但 deleted=0」这种自相矛盾的数据。

### 1.3 可填写判定

`fillable = status == PUBLISHED && 当前时间在 [startTime, endTime) 内`，由后端算好放在 `SurveyVO.fillable`：

- `startTime = null` 视为立即开始；
- `endTime = null` 视为长期有效。

前端不要自己再算一遍时间，两个实现迟早会不一致。截止时间**不依赖定时任务**，每次请求实时判断，避免任务漏跑导致过期问卷仍能提交。

### 1.4 分享码

- 8 位，字符集 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`（去掉了 `0/O/1/I/L` 等易混字符，方便口头传达与手抄）。
- 发布时生成，全局唯一（唯一索引兜底 + 冲突重试 5 次）。
- 查询时**大小写不敏感**（服务端统一 `toUpperCase()`）。
- 草稿无分享码，`shareCode = null`。

## 2.1 问卷列表（分页）

`GET /api/surveys` ｜ 权限 `survey:list:self` 或 `survey:list:all`

**查询参数**

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| keyword | string | — | 模糊匹配标题 |
| status | string | — | `DRAFT` / `PUBLISHED` / `PAUSED` / `CLOSED`，非法值返回 400 |
| category | string | — | `TEACHING` / `ACTIVITY` / `SATISFACTION` / `OTHER`，非法值按 `OTHER` 处理 |
| scope | string | `mine` | `mine` 仅本人创建；`all` 全量，**需 `survey:list:all`** |
| page | int | 1 | 页码 |
| size | int | 20 | 每页条数，**上限 100** |

**权限行为**

- `scope=all` 但无 `survey:list:all` → **403 您没有查看全部问卷的权限**（不静默降级为 mine，否则管理员会以为自己看到的是全量）。
- `scope=mine` 时 SQL 层拼 `create_by = 当前用户`，不做内存过滤。

**响应**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "records": [
      {
        "id": 3,
        "title": "教学质量反馈问卷",
        "description": "请如实填写",
        "category": "TEACHING",
        "categoryLabel": "教学反馈",
        "anonymous": 1,
        "status": "PUBLISHED",
        "shareCode": "Q3PTC5RC",
        "startTime": null,
        "endTime": null,
        "limitOnce": 1,
        "questionCount": 5,
        "answerCount": 0,
        "publishedTime": "2026-11-07 22:48:02",
        "closedTime": null,
        "createBy": 2,
        "createByName": "张老师",
        "createTime": "2026-11-07 22:47:50",
        "updateTime": "2026-11-07 22:48:02",
        "fillable": true
      }
    ],
    "total": 1, "page": 1, "size": 20, "pages": 1
  }
}
```

`createByName` 由批量查询 `sys_user` 填充，避免 N+1。

## 2.2 问卷详情

`GET /api/surveys/{id}` ｜ 权限 `survey:update:self` / `survey:update:all` / `survey:preview`

返回 `SurveyDetailVO` = 列表项字段 + `questions` 数组：

```json
{
  "id": 3, "title": "教学质量反馈问卷", "status": "PUBLISHED",
  "questions": [
    {
      "id": 20, "questionType": "SINGLE", "title": "整体满意度？",
      "description": null, "isRequired": 1, "maxLength": null,
      "ratingMax": null, "sortNo": 1,
      "options": [
        { "id": 41, "content": "非常满意", "sortNo": 1 },
        { "id": 42, "content": "满意", "sortNo": 2 }
      ]
    },
    {
      "id": 21, "questionType": "TEXTAREA", "title": "其他建议",
      "isRequired": 0, "maxLength": 300, "sortNo": 2, "options": []
    }
  ]
}
```

- 题目按 `sort_no` 升序；`options` 对文本/评分题返回**空数组**而不是 `null`，前端可直接 `.map()`。
- 错误：不存在 → 404；他人问卷 → 403。

## 2.3 预览

`GET /api/surveys/{id}/preview` ｜ 权限 `survey:preview`

返回结构与 2.2 完全一致。单独开口子是为了权限语义清晰：预览不该要求 `update` 权限。

## 2.4 按分享码取问卷

`GET /api/surveys/share/{shareCode}` ｜ 权限 `survey:fill`

分享链接落地页用。与 2.2 的差异：

- **不看归属**，任何具备 `survey:fill` 的登录用户都能取到；
- **抹掉 `createByName`**（填写者无需知道谁建的，也避免向学生暴露教师名单）；
- 已暂停 / 已结束 / 未到开始时间**照常返回结构**，由前端按 `fillable` 展示「已暂停回收」等提示——直接 404 会让填写者以为链接失效，反而增加询问成本。

错误：

| 场景 | code | msg |
| --- | --- | --- |
| shareCode 为空 | 400 | 分享码不能为空 |
| 码不存在 / 问卷已删除 | 404 | 分享码无效或问卷已被删除 |
| 无 `survey:fill` 权限 | 403 | 您没有填写问卷的权限 |

## 2.5 新建问卷

`POST /api/surveys` ｜ 权限 `survey:create`

**请求体**

```json
{
  "title": "教学质量反馈问卷",
  "description": "请如实填写",
  "category": "TEACHING",
  "anonymous": 1,
  "limitOnce": 1,
  "startTime": "2026-11-01 08:00:00",
  "endTime": "2026-12-01 23:59:59"
}
```

| 字段 | 必填 | 校验 | 说明 |
| --- | --- | --- | --- |
| title | ✅ | 非空，≤120 字 | — |
| description | ❌ | ≤1000 字 | — |
| category | ❌ | `TEACHING`/`ACTIVITY`/`SATISFACTION`/`OTHER` | 缺省 `OTHER` |
| anonymous | ❌ | 0/1 | 缺省 0（实名）。**匿名不影响后端存 `user_id`** |
| limitOnce | ❌ | 0/1 | 缺省 1（限填一次） |
| startTime | ❌ | `yyyy-MM-dd HH:mm:ss` | 缺省立即开始 |
| endTime | ❌ | 同上，必须晚于 startTime | 缺省长期有效 |

新建后 `status=DRAFT`、`questionCount=0`、`shareCode=null`。

错误：结束时间早于开始 → 400「截止时间必须晚于开始时间」。

## 2.6 修改问卷

`PUT /api/surveys/{id}` ｜ 权限 `survey:update:self` / `survey:update:all`

请求体同 2.5。

**非 DRAFT 状态的限制**：只允许改 `title` / `description` / `endTime`。若请求里 `anonymous` / `limitOnce` / `category` / `startTime` 与库中值不同 → 400：

> 问卷已发布，只能修改标题、简介与截止时间；如需改动结构或设置，请复制为新问卷

> 为什么是「显式报错」而不是「静默忽略」：静默忽略会让调用方以为改成功了，最后变成「我明明设成匿名了」这类扯皮。允许改标题简介是因为这些不影响数据一致性；允许延长截止时间是因为课堂问卷经常需要补时间。

## 2.7 删除问卷

`DELETE /api/surveys/{id}?confirm=false` ｜ 权限 `survey:delete:self` / `survey:delete:all`

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| confirm | false | 已有答卷时必须传 `true` |

- 已回收答卷数 = 0 → 直接删除。
- 已回收答卷数 > 0 且 `confirm=false` → **409**：

  > 该问卷已回收 N 份答卷，删除后数据仍保留但列表不可见；确认删除请传 confirm=true

逻辑删除（`deleted=1`），答卷数据保留，可追溯。

## 2.8 复制问卷

`POST /api/surveys/{id}/copy` ｜ 权限 `survey:copy`

用于「已发布问卷需要改结构」的唯一正确姿势。

| 复制 | 不复制 |
| --- | --- |
| 标题（追加「（副本）」，截断至 120 字）、简介、分类、匿名、限填、全部题目与选项 | 分享码、发布时间、结束时间、答卷数（副本为 0） |

副本 `status=DRAFT`，题目与选项全部重建（新 ID），与源问卷完全独立。

## 2.9 整卷保存题目

`PUT /api/surveys/{id}/questions` ｜ 权限 `survey:update:self` / `survey:update:all`

**只允许 DRAFT 状态**，否则 400「问卷已发布，题目结构已锁定；如需调整请复制为新问卷」。

**请求体**（注意外层包了 `questions` 字段）

```json
{
  "questions": [
    {
      "id": 20,
      "questionType": "SINGLE",
      "title": "整体满意度？",
      "isRequired": 1,
      "options": [{ "content": "非常满意" }, { "content": "满意" }]
    },
    {
      "questionType": "TEXTAREA",
      "title": "其他建议",
      "maxLength": 300
    }
  ]
}
```

> 为什么包一层：Spring 对「请求体直接是 List」的元素级 `@Valid` **不级联**，包一层才能让逐题校验真正生效。

**差量策略**

| 情况 | 行为 |
| --- | --- |
| 带 `id` 且属于本卷 | 原地更新（题目 ID 不变） |
| 带 `id` 但不属于本卷 | 400「题目 ID x 不属于该问卷」 |
| 不带 `id` | 新增 |
| 库里有、本次未提交 | 物理删除（连同选项） |

选项不设历史包袱：**一律删旧建新**。`sort_no` 按数组顺序从 1 重新编号，前端拖拽排序后整卷提交即可。

**题型与字段**

| questionType | 需要 options | maxLength | ratingMax |
| --- | --- | --- | --- |
| SINGLE | ✅ 至少 2 项 | — | — |
| MULTIPLE | ✅ 至少 2 项 | — | — |
| TEXT | ❌ | 1~2000 | — |
| TEXTAREA | ❌ | 1~2000 | — |
| RATING | ❌ | — | 2~10，缺省 5 |

**校验（服务层逐题执行）**

| 情形 | code | msg 示例 |
| --- | --- | --- |
| 题干为空 | 400 | 第 1 道题的题干不能为空 |
| 题干超 255 字 | 400 | 题干不能超过 255 字 |
| 说明超 500 字 | 400 | 题目说明不能超过 500 字 |
| 未知题型 | 400 | 不支持的题型：CHECKBOX |
| 选择题 < 2 项 | 400 | 「整体满意度？」至少需要 2 个选项 |
| 空选项 / 重复选项 | 400 | 「整体满意度？」存在重复选项：满意 |
| 选项超 255 字 | 400 | 「整体满意度？」的选项内容不能超过 255 字 |
| 文本题带选项 | 400 | 「其他建议」不是选择题，不能带选项 |
| 题目数 > 100 | 400 | 单份问卷最多 100 道题 |

成功后 `question_count` 同步更新，返回最新 `SurveyDetailVO`。

## 2.10 发布

`POST /api/surveys/{id}/publish` ｜ 权限 `survey:publish:self` / `survey:publish:all`

前置条件：

1. 当前状态必须是 `DRAFT` → 否则 400「只有草稿状态的问卷可以发布，当前状态：已发布」；
2. 题目数 ≥ 1 → 否则 400「问卷至少需要 1 道题才能发布」；
3. 时间窗合法。

成功后：`status=PUBLISHED`、生成 8 位 `shareCode`、首次写入 `publishedTime`。**题目结构自此锁定。**

## 2.11 暂停 / 2.12 恢复

| 接口 | 前置状态 | 结果 |
| --- | --- | --- |
| `POST /api/surveys/{id}/pause` | `PUBLISHED` | `PAUSED`，填写入口关闭，已收答卷保留 |
| `POST /api/surveys/{id}/resume` | `PAUSED` | `PUBLISHED`；若已过 `endTime` → 400「问卷已过截止时间，无法恢复回收；请先延长截止时间」 |

状态不符 → 400「只有已发布的问卷可以暂停，当前状态：草稿」。

## 2.13 结束

`POST /api/surveys/{id}/close` ｜ 前置 `PUBLISHED` 或 `PAUSED`

`status=CLOSED`，写入 `closedTime`。**不可逆**：结束后的问卷不能再恢复回收，可查答卷与统计。

## 3. 状态码速查

| code | 本模块典型场景 |
| --- | --- |
| 200 | 成功 |
| 400 | 标题为空、时间窗非法、状态不允许该动作、题目校验失败、发布后改结构 |
| 401 | 未登录 / 令牌失效 |
| 403 | 无权限码、操作他人问卷 |
| 404 | 问卷不存在 / 已删除 / 分享码无效 |
| 409 | 删除有答卷的问卷未确认、分享码生成失败 |

## 4. 数据表

| 表 | 说明 |
| --- | --- |
| `survey` | 问卷主表，含 `status` / `share_code` / `question_count` / `answer_count` / `deleted` |
| `survey_question` | 题目表，**无 `deleted`**（草稿阶段删除即物理删除） |
| `survey_question_option` | 选项表，冗余 `survey_id` 便于按问卷批量清理 |

脚本：`deploy/sql/02_schema_survey.sql`。

> `question_count` / `answer_count` 冗余在 `survey` 上：列表页要显示这两个数字，每次都 `COUNT(*)` 会让 20 条记录变成 40 次查询。
